# What do spectral criteria of quantum feature-map kernels actually predict?

Classical simulability, generalization advantage, and the role of task difficulty.

This repository contains the complete, reproducible implementation of the study
"*What do spectral criteria of quantum feature-map kernels actually predict?*" —
a task-resolved numerical investigation of when spectral statistics of quantum
kernel matrices (effective rank, spectral entropy, concentration, gap ratio)
predict **classical simulability** versus **generalization advantage**.

## Highlights

| Finding | Result |
|---|---|
| Spectral criteria predict classical simulability | all five criteria significant; top-5 energy ρ = −0.80 (*p* = 1.2e−15) |
| Spectral criteria do **not** predict quantum advantage | global ρ ≈ 0.02 (*p* = 0.76); sign unstable across tasks |
| Advantage is driven by classical baseline saturation | ρ = −0.65 (*p* = 2e−27); positive advantage never observed on real data (0/48) |
| Frequency scale is the dominant design knob | ρ = +1.000 for spectral spread and simulability |
| Kernel-target alignment is absorbed by difficulty | global ρ = −0.42; after controlling for difficulty, ρ = +0.001 (*p* = 0.99) |
| Noise *type* controls criterion validity | survives depolarization (ρ = +0.35), breaks under amplitude damping (ρ = +0.04) |

See the manuscript PDF in `paper/` for the full analysis.

## Repository layout

```
src/         self-contained state-vector simulator + feature maps + spectral criteria
             + classical baselines + task generators (pure NumPy, no quantum libraries)
scripts/     experiments exp01–exp11 + figure generation scripts
tests/       unit tests for the simulator (unitarity, encoding normalization)
results/     raw CSV outputs of all experiments + experiment memos (incl. bug-fix history)
figures/     all figures (PDF vector + PNG previews)
paper/       manuscript source (LaTeX quantumarticle template) and compiled PDF
docs/        project design document (with final hypothesis status)
```

## Requirements & quick start

Python ≥ 3.10, NumPy, SciPy, scikit-learn, matplotlib, pandas. No quantum SDKs.

```bash
pip install -r requirements.txt

# 1. verify the simulator physics (unit tests)
python3 tests/test_simulator.py

# 2. reproduce the main experiments
python3 scripts/exp01_feasibility.py
python3 scripts/exp03_spectral_threshold.py
python3 scripts/exp03_supp_difficulty.py

# 3. regenerate all figures as PDF vector graphics
python3 scripts/make_pdf_figures.py
python3 scripts/make_pdf_figures_round2.py
```

Every experiment writes its results to `results/` as CSV. All random processes
use fixed seeds; results are reproducible end-to-end.

## Reproducibility notes

- The simulator is a state-vector implementation in NumPy with **no dependence
  on external quantum libraries**.
- Unit tests assert gate unitarity and that every feature-map encoding produces
  normalized states; these tests caught two real coding errors during
  development (see `results/实验结果备忘03-最终版.md` for details).
- Figures are generated by plotting scripts directly from result CSVs; **no
  image-generation model was used**.
