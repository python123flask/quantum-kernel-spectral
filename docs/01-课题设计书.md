## 1. 研究背景与动机

### 1.1 量子机器学习（QML）的核心困惑

量子机器学习最有吸引力的一环，是"是否真的存在量子优势"：用量子特征映射把经典数据嵌入指数维 Hilbert 空间，是否能让经典模型做不到的事情？

过去几年，这个乐观叙事被一系列**负面结果**冷却：

- **量子核集中（exponential concentration）**：Thanasilp 等（2024，Nature Communications 引超 350）证明，量子核方法在数据嵌入、全局测量、纠缠、噪声四种来源下会产生指数级集中，导致核矩阵丧失判别力。`[Thanasilp2024]`
- **经典可模拟性（dequantization）**：一系列工作证明，大量"看似量子"的模型可以被经典算法高效替代。Sweke 等（2025）用 Random Fourier Features（RFF）系统研究了对变分 QML 模型的"去量子化"。`[Sweke2025]`
- **"copycat theorem"**：一些"避免贫瘠高原"的量子神经网络被证明可被经典高效模拟（LANL 2026 研究）。`[LANL2026]`

### 1.2 未解决的缝隙

现有工作可以归为两类：

1. **后验判定**：训练完之后，才发现量子模型没优势（或可被经典替代）。
2. **分类别讨论**：针对某个特定模型类（如某种核、某种变分电路）给出可模拟性证明。

**缺的是一类"先验 + 统一 + 可计算"的判据**：给定一个量子特征映射，在**投入昂贵的量子计算或训练之前**，能否用一个**高效可计算的谱判据**预测：

- 这个映射的量子核是否会集中 / 丧失判别力？
- 它是否（大概率）可被一个低秩或 RFF 经典模型在泛化能力上匹配？
- 它的"有效优势"空间有多大？

**这正是本课题要填补的缝隙。**

## 2. 科学问题与研究假设

### 2.1 核心科学问题

> 对任意构造的量子特征映射，能否基于其 **量子核矩阵的谱结构（特征值分布）+ 特征映射的傅里叶谱**，构造一个高效可计算的标量判据，在**训练前**预测该量子核的经典可模拟性（即能否被 RFF 或低秩经典核匹配）？

### 2.2 核心假设（最终验证状态，2026-09-06）

> 以下假设已通过 exp01-05 全部验证（发现并修复编码 bug 后重跑，数字为最终版）。详见 results/实验结果备忘03-最终版.md。

- **H1（谱-可模拟性假设）✅ 强成立**：量子核矩阵谱集中度与其经典可模拟性正相关。
  *最终证据：top5_energy rho=-0.804 (p=1.2e-15)；spectral_entropy rho=+0.674 (p=9.9e-10)；effective_rank rho=+0.610 (p=8.8e-8)；全部 5 个谱判据 FDR 校正后显著，方向一致*
- **H2（傅里叶-集中假设）✅ 强成立**：特征映射的傅里叶谱宽度控制核谱分散度与经典可模拟性。
  *最终证据：freq_scale→effective_rank rho=+1.000 (p=1.4e-24)；freq_scale→RFF 误差 rho=+1.000 (p=1.4e-24)，完美单调*
- **H3（优势-谱假设）❌ 彻底证伪**：量子泛化优势与谱判据不存在一致关系。
  *最终证据：跨任务全局全部不显著（eff_rank rho=-0.02 p=0.76；谱熵 rho=-0.05 p=0.45）；任务内方向不一致（cross_high rho=-0.63 显著负 vs noisy +0.34 正 vs 单任务 +0.38 正）——同一判据出现正、负、无三种结果*
- **H4（数据依赖假设）✅ 成立**：谱判据强烈数据依赖（由数据分布形状主导）。
  *最终证据：CV=0.06~0.38（iqp 0.38 / angle 0.33 / variational 0.25）；PCA 内在维度仅边缘相关（rho=+0.167, p=0.068）*

**新增核心假设（全项目最强结论）**：

- **H5（优势窗口=经典难度假设）✅ 成立**：量子核的相对优势由**经典基线在该任务上的饱和程度**主导。
  *最终证据：全局 rho=-0.651 (FDR q=4.2e-26)；任务级单调（经典基线 0.52-0.55 → 正优势配置 28-39%；经典基线 ≥0.86 → 0%）*

### 2.3 判据的具体形式（初步）

拟构造的谱判据候选（在代码中逐个实现并评估其一阶判别力）：

- **有效秩比值**：`r_eff / d_H`，其中 `r_eff = (Σλᵢ)²/Σλᵢ²`，`d_H` 为核矩阵维数。
- **谱熵（Shannon entropy of normalized spectrum）** `H = -Σ p_i log p_i`。
- **集中度（participation ratio）** `PR = 1/Σ p_i²`。
- **核矩阵的"远离恒等"程度 / 与 RFF 核的希尔伯特-施密特距离**。
- **数据依赖性判据**：结合数据分布与核谱的相互作用。

## 3. 研究方法与技术路线

### 3.1 总体路线（五阶段）

```
Phase A  建立自研状态向量模拟器（纯 numpy）
Phase B  实现多种量子特征映射 + RFF 经典对照
Phase C  实现谱判据计算模块
Phase D  大规模数值实验：谱判据 vs 可模拟性 vs 泛化优势
Phase E  数据分析（统计功效 + 多重比较校正）+ 论文撰写
```

### 3.2 关键技术组件

**A. 状态向量模拟器**（`src/simulator.py`）
- 纯 numpy 实现，无外部量子库依赖
- 支持：单/双比特门、变分层、数据重载（encoding）、测量
- 目标规模：5-12 个 qubit（CPU 可行）

**B. 量子特征映射族**（`src/feature_maps.py`）
- 角度编码（angle encoding）
- IQP（instantaneous quantum polynomial）
- 变分特征映射（variant of Havlíček et al.）
- 高维/纠缠增强映射
- 每种带"注入噪声/调控纠缠"旋钮，用于扫描谱结构

**C. 经典对照**（`src/classical_baselines.py`）
- Random Fourier Features（RFF）核近似
- 低秩核近似（Nyström）
- 经典核（RBF / 多项式）
- "匹配谱"的经典模型（在同一个展平表示的普基底上，只保留相位信息）

**D. 谱判据**（`src/spectral_criteria.py`）
- effective rank、谱熵、participation ratio、集中度
- 与 RFF 的距离度量

**E. 数据与任务**
- 可控合成任务（能控制"量子优势是否存在"的 ground truth）
- 标准 benchmark（UCI 小数据集）

### 3.3 可复现性设计
- 所有随机实验固定 seed
- 每个实验输出：实验配置（JSON）+ 数值结果（CSV）+ 图（PDF）+ 可复现脚本
- 代码自包含，无外部量子库依赖

## 7. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 量子优势本就微弱的广泛氛围导致结果全是"负面" | 把"何时失效"当作正当贡献；负面/判定结果同样是可发表的科学结果 |
| 计算量超 CPU 负载 | 严格限制 qubit 数（≤12）+ 实验矩阵稀疏化 + 采样而非全量 |
| 判据一阶判别力不足 | 设计多候选判据 + 统计检验筛选，允许"组合判据" |
| 无导师，方向漂移 | 以本设计书为锚，每阶段完成即有产出，避免无限扩展 |
