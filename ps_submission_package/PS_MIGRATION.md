## 第二步（10 分钟）：Overleaf 迁移

1. overleaf.com → New Project → **Browse Templates** → 搜索 **"IOP"** → 选 **"IOP Publishing"** 官方模板（基于 iopart 类，自带完整环境）
2. 模板里会有一个 sample 文件（如 `iopart-sample.tex`），**只需替换以下位置**：

| 位置 | 改成 |
|------|------|
| `\journal{...}` | `\journal{Phys. Scr.}` |
| `\title{...}` | 论文标题：What do spectral criteria of quantum feature-map kernels actually predict? Classical simulability, generalization advantage, and the role of task difficulty |
| 作者块 | `\author{Xianzhe Liu}` + `\affiliation{School of Physics and Electronics, Hunan University, Changsha 410082, China}` + 邮箱命令（模板示例写法，通常是 `\ead{liuxianzhe@hnu.edu.cn}`） |
| `\begin{abstract}...\end{abstract}` | 从 content_source.tex 的 `\begin{abstract}` 段整段复制 |

3. **正文 100% 复用**：打开 `ps_submission_package/content_source.tex`，把 `\section{Introduction}` 到 `\bibliography{refs}` 之前的**全部正文**复制到 Overleaf 模板正文区（图/表/公式命令完全兼容）：
   - 5 张图（fig1-5.pdf）上传到项目根；`\includegraphics{figX.pdf}` 保持原名
   - 表格子（booktabs）需要 `\usepackage{booktabs}`——模板若没有就在导言区加一行
4. 上传 `refs.bib`，使参考文献命令为：
   ```
   \bibliographystyle{iopart-num}
   \bibliography{refs}
   ```
   （以模板样例里的引用命令为准）
5. Recompile → 下载 PDF

**如果编译报错：把报错信息原样发给我，我马上给你对应的修正**（这是本方案唯一需要回环的地方）。
